What shipped in each release, newest first. Every tagged version builds the same
set of artifacts: archives for Linux, macOS, and Windows on amd64 and arm64,
Linux packages (deb, rpm, apk), a multi-arch container image on GHCR, a
CycloneDX SBOM per archive, and a `checksums.txt` signed with keyless cosign.
The Homebrew cask and the Scoop manifest go out with it when the tap tokens are
configured. Binaries are pure Go, so there is nothing to install alongside
them.
